# NMI-track archive (inactive)

Superseded Nature Machine Intelligence submission artifacts, archived after the
project retargeted to *Molecules* (MDPI). Kept for record only; not maintained.

- `NMIPaper.html` / `NMIPaper.docx` - NMI Article main text
- `NMIPaperSI.html` / `NMIPaperSI.docx` - NMI Supplementary Information
- `ExtendedDataTable1.docx`, `NMI_ExtendedData.zip` - NMI Extended Data
- `nmi_cover_letter.html` - NMI cover letter

The active submission is the *Molecules* pair in `paper/molecules/`, generated
from the long-form preprint `paper/long_paper.html`.
